关键模块剖面

013 网络源码

RestorationBlock · 基础恢复块

1×1 · C→3C→局部 2C / 门控 C→DWConv 与门控→1×1 · 2C→C

局部 2C 先做逐通道空间卷积，再分成 a、b。一半走 GELU，一半乘以独立 C 通道的 sigmoid 门。通过可学习逐通道缩放 α 加回输入，α 初值 0.1。每阶段内 3×3、5×5 交替。

x + α · Conv₁×₁([GELU(a), b ⊙ sigmoid(g)])

013c/013e 在 middle.5.1 与 dec.0.3 改用两层全 3×3 卷积，中间接 GELU，保留残差缩放。

HazeConditionedFusion · 分带跳连

1×1 对齐 skip→5×5 均值 → 平滑 L↘差分 → 细节 H

对深层特征 D、平滑差 L−D、细节强度 |H| 做 2×2 降采样池化。区域支路用 1×1 和逐通道 3×3 建模，叠加全局池化得出的场景条件，再预测双线性上采样的两组增益。

F = D + gL ⊙ L + gH ⊙ H，g = 2·sigmoid(logit)

末层零初始化使两组增益初值为 1，融合初始为 D + 对齐后的跳连。

LFM · 低频特征调制

rFFT2 → 软径向低通 → irFFT2∥16×16 池化 → γ、β → 上采样

一支得到低通 LP(x)，另一支用 16×16 池化特征预测随位置变化的缩放和平移。软掩码 cutoff 为 0.08，过渡参数 0.04，半径按特征图短边对应的 Nyquist 尺度归一化。

x + γ ⊙ LP(x) + β

调制预测末层零初始化。013 和 011p 共用实现，两次调制所在尺度与后续通路有区别。LFM 源码

RegionContext · 区域交叉注意力

逐像素 Q×最多 8×8 个池化 K/V→8 头 → 1×1 投影

在 64×64 瓶颈上，4096 个位置各自查询 64 个区域描述。投影后的跨区上下文按可学习逐通道系数加回原特征，初值 0.01。

x + α · proj(softmax(QKᵀ / √d) V)

放在 LFM₁ 之后、第二组恢复块之前。区域描述的分辨率和后续解码器都会影响恢复的空间精度。

DetailRefinement · 条形核细节修复

x − AvgPool₅×₅(x)→1×1 分两路→DW 1×9 / 9×1→拼接 · 门控 · 1×1

位于 1/2 解码末端，处理两个方向的局部对比。门控从完整的 x 预测，输出投影零初始化后以残差形式注入。

可用海天线、船体边缘检查效果。方向收益可用等成本的方形核对照验证。

LowFrequencyRGBHead · 013d 低频头

末端特征与雾图池化→16×16 拼接→两层 3×3 · 64 通道→1×1 RGB

把低分辨率 RGB 修正双线性放大到输入尺寸，与常规 RGB 残差并联。末层零初始化，起点沿用 013b 的输出形式。

Ĵ = crop(Ipad + ΔRGB + up(ΔRGB₁₆×₁₆))

检查跳连

区分雾与真实色调

先导出 fuse[1] 的低频和细节增益图，并按上下区域对照残雾、亮水面、白色船身。现有平滑 skip 可能同时携带雾幕、天空和水面本色，可在 1/2 尺度单独尝试用 L−D 修正深层特征，同时保留细节注入。通过同预算重训和配对指标判断两类误差是否一起改善。

RegionContext 的推理旁路影响很大，首轮保留它。当前区域注意力没有显式坐标。若误差持续集中在海天线附近，可比较 8×8 与 4×16 池化，保持 64 个 token，检验横向分辨率是否有用。再单独验证相对高度信息，避免同时改池化和注意力。
