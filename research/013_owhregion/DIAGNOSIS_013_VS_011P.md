### 1.4 误差拆解与关键实证事实

1. **并非“收敛慢”，而是结构天花板显著偏低**：
   - 从 8k 拉长到 60k（训练量 ×7.5），013a 相对 011p 的 Mist 差距几乎零缩窄（−3.03 → −2.76 dB），Dense 也仅缩窄 0.37 dB（−2.02 → −1.65 dB）；60k 终点上 011p 在 Dense 85.1% (80/94)、Mist 86.2% (81/94)、Moderate 87.4% (83/95) 的单图上全面胜出。
   - 不论 8k 还是 60k，013a/b/c **全面落后于仅 6.36M、50 GMACs 的普通 ResBlock 骨架 WaveletUNet**（013b@8k 即使把计算量加到 140.4 GMACs，依然比 WaveletUNet 低 0.53 / 1.24 / 1.08 dB）。
2. **013b vs 013c（等参 9.3M 对照）**：
   - 8k 全量配对：`013c − 013b` 为 Dense −0.172 dB (`[-0.323, -0.026]`) / SSIM −0.00280、Mist +0.035 dB（区间跨零）、Moderate −0.171 dB (`[-0.376, +0.029]`) / SSIM −0.00230。
   - 差距 96.7% (Dense) / 88.5% (Moderate) 在低频，`undershoot_mse` 与 `grid_boundary_error` 同步变差。说明**将 1.71M 参数局部堆在 1/8 和 1/4 末端各一块，性价比远不如浅中层加宽**；但浅中层加宽（013b）相对 013a 也只追回 +0.35/+0.37/+0.55 dB，距 011p 仍有 1.67–2.66 dB 鸿沟，**单纯堆容量绝非解药**。
3. **分频段与雾度分层归因（`013b@8k` vs `011k_dea@8k` 逐图对齐）**：
   - **频段占比**：总 MSE 差距的 **85.1% (Dense) / 88.6% (Mist) / 83.7% (Moderate)** 落在低频（`<0.02` Nyquist），10%–14% 在中频（`0.02~0.15`），仅 1.6%–2.6% 在高频（`>0.15`）。60k 终点上 `013a` vs `011p` 保持一致（低频占 75.9% / 84.7% / 74.1%，中频占 18.6% / 12.3% / 19.8%）。
   - **校正方向失衡**：`013b` 的 `undershoot_mse`（去雾不足）比 011p 高 **48%–107%**（Dense 0.01113 vs 0.00753，Mist 0.00343 vs 0.00171，Moderate 0.00601 vs 0.00290）；同时 Mist 的 `overshoot_mse`（过校正）高达 011p 的 **1.96 倍**（0.00161 vs 0.00082）。
   - **最轻雾反而输得最惨**：按 `input_smooth_mse` 三等分后，Mist **最轻三分之一样本上 `011p − 013b = +3.88 dB`**（中/重三分位为 +2.37 / +1.75 dB），Moderate 最轻三分位亦高达 +2.68 dB。
4. **视觉失效模式（基于 `worst_gap_montage.jpg`）**：
   - 013a 在 `Mist_07030`（白色筒仓大片变灰暗）、`Mist_03278`（干净天空大面积棕灰污斑）、`Dense_08155`（白帆暗斑）、`Moderate_07447`（烟囱右侧晴空黑烟状晕染）上出现严重的**非局部色调污染/暗斑过校正**；同时在 `Moderate_08962`（背景黑船体发灰）上出现严重**去雾不足**。
5. **垂直高度色调空间巨大（`color_headroom_internal60.csv`）**：
   - 60k 终点的 013a 输出，仅做全局 RGB 仿射即可涨 +2.0~2.1 dB，**允许仿射参数沿图像高度线性变化后可再涨 +0.5~1.0 dB**（Dense 24.99→27.72，Mist 28.65→31.74，Moderate 27.51→29.96），直接揭示了海事图像沿垂直高度（天空→海天线→近景海面）存在强烈的一维平滑雾度梯度。

## 2. 代码级五大结构硬伤（对照 `owh_lfm_unet_arch.py` 与 `deanet_v3_arch.py`）

### 硬伤 1：`RegionContext` 无归一化 8×8 全局空间自注意力——制造天空/白墙暗斑，重蹈 004b 覆辙

源码：`basicsr/archs/owh_lfm_unet_arch.py:151-174`。

- **结构问题**：将瓶颈特征池化到固定 `8×8`（64 个区域 token），在**无 LayerNorm / QK-Norm、无空间位置编码**的情况下做全局点积注意力 `softmax(Q K^T / sqrt(d)) V`，且 `scale=0.01`（非严格零初始化）。
- **物理失效机制**：海事图像中的晴朗天空、白色船帆、白色建筑在亮度和纹理平滑度上与浓雾高度相似。无位置偏置的点积注意力会将远处暗船体或浓雾块的低频特征跨区域错误搬运至干净高亮区域，直接产生 `worst_gap_montage.jpg` 中的块状暗斑与 Mist 最轻雾 `+3.88 dB` 崩盘。训练图 512² 与测试大图（如 536×800）在固定 `8×8` 网格下还存在空间感受野尺度漂移。
- **与历史证据一致**：本仓库 `004b`（`research/004_lowfreq/README.md §7.3`）已独立证明瓶颈处无约束全局注意力（MDTA）会严重破坏低频结构（Dense −4.5 dB，Mist −7.4 dB）。
- **澄清 `module_interventions_internal24.json` 的误导**：训练后置零 `RegionContext` 掉至 12 dB 只反映它位于瓶颈主链中央并带非零初始权重，训练后与主干低频直流偏置发生**强共适应**（与 011i 置零掉 4.6 dB 但独立训练净收益为负属于同一统计现象），不能作为正向贡献的证据。

### 硬伤 2：4 尺度过度下采样（瓶颈 1/8），导致 LFM 物理截止频率减半且浅层营养不良

尺度级参数与算力分布对照（512×512 输入）：

| 尺度 (分辨率) | 011p (`DEANetV3`) Params / GMACs | 013a Params / GMACs | 013b Params / GMACs |
|---|---:|---:|---:|
| **1× (512)** | 0.347M / **39.11G** (8×DEBlock) | 0.085M (1.1%) / **16.67G** | 0.146M / 28.57G |
| **1/2 (256)** | 1.466M / **47.80G** (8×DEBlock+CGA) | 0.505M / **28.00G** | 0.882M / 49.18G |
| **1/4 (128)** | **6.067M / 49.27G** *(瓶颈: 8×DEABlock+2×LFM)* | 1.919M / 27.26G | 3.030M / 43.91G |
| **1/8 (64)** | *无（不下采样到 1/8）* | **5.028M (67%)** / 17.71G | **5.274M (57%)** / 18.71G |

- **频带数学错位**：`LowFreqModBlock._soft_lowpass_mask`（`deanet_v3_arch.py:61-67`）按**当前特征图 Nyquist** 定义截止频率 `cutoff=0.08`。
  - 在 011p 的 1/4 瓶颈（128×128，Nyquist=64）上，`cutoff=0.08` 覆盖半径 `5.12` 个周期/图，对应 512px 原图归一化频率 **`0.020`**，精准对准 `DC~0.02` 残差主频带。
  - 在 013 的 1/8 瓶颈（64×64，Nyquist=32）上，原样复用 `cutoff=0.08` 只覆盖半径 `2.56` 个周期/图，对应原图归一化频率 **`0.010`**（**二维频谱覆盖面积骤缩至 1/4**），漏掉了 `0.01~0.04` 关键雾幕过渡带。（同样解释了瓶颈在 1/16 的 WaveletUNet 截止频率缩至 `0.005` 而在低频大败。）
- **算力错配**：013a 将 67% 参数压在 1/8 粗糙尺度，1× 全分辨率仅分到 1.1% 参数与 4 个轻量块；而顶刊去雾主干（DEA-Net、DehazeFormer、gUNet、SFNet、FocalNet、OKNet、ConvIR）普遍采用 **3 尺度（仅 2 次下采样，瓶颈在 1/4）**，保证密集像素回归的空间精度与高分辨率表达力。

### 硬伤 3：`RestorationBlock` 结构孱弱且算术强度极低

源码：`basicsr/archs/owh_lfm_unet_arch.py:11-24`。

1. **缺乏全局通道统计（无 GAP 通道注意力）**：`context` 分支仅是逐像素 1×1 投影，感受野为 1×1；而 011p 的每个瓶颈 `DEABlock` 都含完整 CGA（GAP 通道注意力 + 7×7 空间注意力 + 7×7 逐像素门控），NAFNet / OKNet / ConvIR 等顶会块亦在每块内配备 GAP 通道统计以稳定全局色彩。
2. **弱空间交互 + 门控易饱和**：仅含单层 depthwise 3×3/5×5，无跨通道空间卷积；通道被硬劈为 `GELU(a)` 与 `b * sigmoid(context)`，无归一化控制下 `sigmoid` 易饱和。相比之下，011p 的 `DEBlock` 含两层密集 3×3 卷积（首层为 5 分支差分重参数化 `DEConv`，训练期隐式多路径优化增益显著）+ 块内双残差。
3. **全网 24 块统一 `scale=0.1`**：在无 Pre-Norm 下把残差更新与早期参数梯度压缩 10 倍，严重拖累前 8k 步有效深度收敛。
4. **Memory-Bandwidth Bound 导致显存爆炸与速度崩溃**：高分辨率上频繁 `1×1 扩 3C → DWConv → chunk/cat` 与 `HazeConditionedFusion` 的多张量拼接使激活显存暴涨（不开 `activation_checkpointing` 在 bs16@512 直接超 47 GiB OOM），开启重计算后 013b 耗时 **3.07 s/iter**（比无重计算的 011p 慢 **3.7 倍**）。

### 硬伤 4：`HazeConditionedFusion` + 最外层 `padded + correction` 构成“双重浓雾直通漏洞”

源码：`basicsr/archs/owh_lfm_unet_arch.py:148, 177-201`。

1. **非凸叠加，初始 100% 灌入浅层雾幕**：`2 * sigmoid(0) = 1.0`，输出 `deep + low_gain * smooth(skip) + detail_gain * detail(skip)` 且缺少融合后 `1×1 Conv` 通道重映射。尤其在 **512×512 全分辨率跳连 `fuse[2]`** 上，浅层 `skip` 几乎是原始浓雾拷贝；叠加最外层的纯加性残差 `padded + correction`，解码器末端被迫用 2 个 `scale=0.1` 的弱块硬抵消整幅图像的低频雾幕偏置。
2. **5×5 均值滤波分频过窄**：在 512px 下无法区分雾幕与中频物体结构，迫使 `low_gain` 在“压雾幕”和“保轮廓”间两难。
3. **对比 011p**：DEANet 在 512 全分辨率**无 skip connection**、最外层**无 `x + out` 加性跳连**，1/4 与 1/2 的 `CGAFusion` 采用**凸组合** `pattn2 * x + (1 - pattn2) * y` + `1×1 Conv` 重映射。
4. **物理形式劣势**：大气散射逆方程 $J = (1/t)I - A(1-t)/t$ 同时需要**乘性对比度恢复**与**加性去幕**；纯加性残差 $I + \Delta$ 在浓雾区必须硬凑 $(1/t-1)(I-A)$，直接造成 `undershoot_mse` 高出 011p 50%–100%。

### 硬伤 5：上/下采样伪影与低收益细节模块

- 裸 `Conv1×1 + PixelShuffle(2)` 缺乏子像素空间平滑，使 013a 的 `grid_boundary_error` 在三个子集均劣于 011p；
- `DetailRefinement` 置零后 PSNR 仅降 0.22–0.50 dB、`low_mse` 纹丝不动（`module_interventions_internal24.json`），属于非瓶颈投入。

## 3. 决策：暂缓 013d / 013e，直接转向 014 新基座

- **为何不继续跑 `013d`（013b + 16×16 低频头）**：本质与本仓库已验证的 `011i`（8k 净收益 Dense −0.06 / Mist +0.32 / Moderate −0.08 dB）同构；在已被 `RegionContext` 污染的末端特征上贴低频补丁，无法修复上述四大根因，预期远不足以填平 1.67–2.66 dB 差距。
- **为何不继续跑 `013e`（013b + 013c，11.29M）**：013c 自身已败于 013b，叠加只会继续放大参数、显存与训练耗时。
- **为何跳过 013a 止损消融**：五大结构硬伤已有完备的代码、频谱、分层统计与视觉证据支撑，且 013a 4 尺度框架本身存在显存/速度瓶颈；为节省 GPU 周期、尽快获得超越 011p 且原生面向后续真实海雾 LoRA 适配的高性能预训练主干，**直接启动 `014` 新基座构建**（完整方案见 `research/014_maritime_sfnet/README.md`）。
