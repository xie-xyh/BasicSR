# 004 — 内容自适应低频全局模块（DEANetV3）：003d 失败后的重构

> 设计文档。前置结论：`research/003d_deanetv2/README.md` §6–§7（FGB 失败归因）。
> 实验：`004a_DEANetV3-LFM_...`（LFM 频域低频路径）、`004b_DEANetV3-MDTA_...`（空域通道注意力对照）。
> 配置：`options/train/DEANet/train_DEANet_004a_lfm_512.yml` / `train_DEANet_004b_mdta_512.yml`。

## 1. 从 003d 归因数据得到的设计约束

003d 的两个探针实验给出的硬事实：

1. **低频仍是最大误差源**：残差能量的 55–61% 集中在 DC~0.02 Nyquist 频段（退化本身 86.5% 也在此），003c 的 FFTLoss 只压掉一部分（该频段 001→003c 仅 −14%）——全局低频方向**仍然成立**；
2. **静态滤波器做不了这件事**：FGB 的复数滤波器与输入无关，学成中高频调制器（能量 62–69% 在 r≥12），DC 频段几乎没学到（4.2%/1.8%），且使 DC~0.02 残差能量比 L1 基线还差 +13.6%；
3. **归一化有害**：FGB 的 GroupNorm(1) 在 FFT 前按样本归一化整幅特征图，抹掉了全局均值/色调统计；
4. **零初始化残差分支是有效的工程手段**（003d 训练稳定，问题不在优化）。

→ 新模块必须同时满足：**内容自适应**（按输入图决定怎么调）、**只作用低频**（不与 DEConv 高通主干抢高频）、**不做归一化**（保留全局统计）、**零初始化**（不扰动既有堆叠）。

## 2. 近两年相关工作怎么解决同一问题

| 工作 | 做法 | 对本设计的启示 |
|---|---|---|
| [AdaIR](https://arxiv.org/abs/2403.14614)（ICLR 2025，all-in-one 复原 SOTA，含去雾） | 从**退化输入的频谱自适应地**解耦低/高频（掩码由输入生成，非静态），双向交互后融合 | 频率解耦的掩码必须 content-adaptive —— 正是 FGB 缺的那一半 |
| [SFHformer](https://github.com/deng-ai-lab/SFHformer)（ECCV 2024） | 空域多尺度卷积（局部）+ 频域全局 FFN 混合；频域分支负责全局/低频 | 频域路径与空域路径**分工**而非全频带通吃；其有效形态是"动态核+门控"，不是纯静态滤波 |
| [Fourmer](https://proceedings.mlr.press/v202/zhou23f.html)（ICML 2023） | 频域核预测（kernel prediction）做全局建模 | 频域全局操作同样以输入条件化（预测核）才有效 |
| [Restormer](https://arxiv.org/abs/2111.09881)（CVPR 2022，近年所有复原 backbone 的标配构件） | MDTA 通道自注意力：内容自适应全局操作，空间复杂度线性 | 提供"非频域的内容自适应全局模块"对照 |
| [DFSA-Net](https://www.sciencedirect.com/science/article/abs/pii/S0957417425044689)（2025 去雾） | 专用频域模块分解高/低频分别处理 | 去雾领域同样收敛到"解耦 + 分治" |

共同点：**近期有效的频域模块全部是输入条件化的**（自适应掩码/预测核/门控），且低/高频分治。FGB 的"全频带静态滤波"两条都违反了。

## 3. 模块设计（`basicsr/archs/deanet_v3_arch.py`）

### 3.1 LowFreqModBlock（LFM，004a，主力候选）

```
low  = irfft2( rfft2(x) ⊙ M )                    # M: 软低通掩码（cutoff 0.08 Nyquist，sigmoid 软边 0.04）
g    = upsample( Conv1x1( GELU( Conv3x3( avgpool16×16(x) ) ) ) )   # 内容自适应调制图
γ, β = split(g)                                  # B, C, H, W，由 16×16 低分辨率视野预测
out  = x + γ ⊙ low + β                           # 零初始化 → 初始严格恒等
```

逐条对应设计约束：

- **内容自适应 + 空间变化**：γ/β 不是全局标量，而是从 16×16 下采样视野预测后上采样的**平滑空间图**——雾浓度/色调在空间上平滑变化，调制量也随位置平滑变化（贴近透射率场的物理形态），这正是 06931 夜景色调错误所需要的"看图校正"；
- **只调低频**：软掩码 M 把 FiLM 的作用对象限制在 <0.08 Nyquist（覆盖 §7.2 残差最集中的 DC~0.06 区间），高频分量完全不经过该分支，不可能与 DEConv 抢高频（003d 的失败机制 (c) 从构造上排除）；
- **无归一化**：保留全局 DC/色调统计（排除机制 (b)）；γ 缩放低频分量、β 直接注入平滑偏置，两者都是低频操作；
- **零初始化**：输出卷积置零 → 初始严格恒等（单元测试验证 max|out−in| = 0）；
- **任意分辨率**：掩码按实际频谱形状现算；参数量极小（7.88M vs DEANet 7.79M，+1%），bs20 @ 512px 峰值 44.6 GiB，与 003c（45.5 GiB）一致，**batch 与 003c 严格对齐**。

### 3.2 MDTABlock（004b，对照）

Restormer 式 MDTA 通道自注意力 + GDFN 门控 FFN，输出投影零初始化（同样严格恒等）。作用：**分离变量**——004a 与 004b 同为"内容自适应全局模块"，差别在频域低频限定 vs 空域通道注意力。若 004b 有效而 004a 无效 → "内容自适应"是关键，低频限定不重要；若 004a 显著优于 004b → 低频限定带来额外收益，支持频率分治路线。

### 3.3 插入位置

与 003d 完全相同：level3 瓶颈 8×DEABlock 之间 2 处（DEA,DEA,GB,DEA,DEA,GB,DEA,DEA），其余结构不动。`DEANetV3(global_block='lfm'|'mdta')` 单类双变体，继承 DEANetV2 只替换两个块。

## 4. 实验设计

| 实验 | 网络 | 唯一变量 | 显存/bs |
|---|---|---|---|
| 003c（对照） | DEANet | — | bs20 @ 45.5 GiB |
| 003d（已完成，负结果） | DEANetV2（FGB 静态滤波） | 静态全频带频域块 | bs16 @ 39.3 GiB |
| 004a | DEANetV3 + LFM | 内容自适应低频块 | bs20 @ 44.6 GiB（与 003c 严格对齐） |
| 004b | DEANetV3 + MDTA | 内容自适应空域注意力 | bs16 @ 42.5 GiB（bs20 OOM，同 003d 偏差） |

数据/loss（L1+FFT 1.0+Grad 0.2）/512px/60k/lr 1e-4/EMA/seed 全部与 003c 一致。双卡并行各跑一个，预估各 ~18h。

**判据**（训练完成后用 003d 的两个探针复验，`research/003d_deanetv2/tools/` 直接复用）：

1. 主指标：Dense-test 全量 PSNR/SSIM > 003c（24.72/0.9006）；
2. 机理验证：残差频谱 DC~0.02 频段绝对能量 < 003c 的 250.6M（003d 是 332.5M，001 是 292.8M）——若指标升但低频能量没降，说明收益来自别处，需重新归因；
3. 004a 的 γ/β 调制图可视化（hook 导出 06931/07619 等失败案例的 β 图），确认模块确实在做空间平滑的色调校正；
4. 若 004a/004b 均无效 → 低频误差可能对"瓶颈处后处理校正"不敏感，转向显式低频分支（003 README §3 方案 2）或物理引导（方案 4）。
