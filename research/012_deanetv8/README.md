# 012 — 自适应频率边界的双路去雾网络（DEANetV8）：低频全局通路下钻

> 设计文档。前置阅读：`research/004_lowfreq/README.md`（LFM 验证与设计约束）、`research/009_freqbranch/README.md`（未实施的低频分支原案）、`research/007_rf_capacity/README.md`（感受野推导与堆叠失败）、`research/sota_benchmark/SOTA_2025_2026.md`（领域趋势与 AdaIR 等先验工作）。
> 一句话：把 LFM 的"固定边界 + 调制"升级为"**内容自适应频率边界 + 有容量的低频平行通路**"，主干与高频路径不动。

## 1. 证据链（为什么是这个方向）

本项目 003~011 系列确立的硬事实：

1. 残差能量 55~61% 集中在 DC~0.02 超低频带（全局色调/残雾）；DEA-Net 瓶颈理论感受野 ~197px（有效 60~70px），3×3 卷积堆叠天然够不到全局（007 §1）；
2. **LFM（FFT 软掩码低频带 + 内容自适应 FiLM）是唯一验证有效的结构改进**（004a：Dense +0.13dB，DC~0.02 残差 −4.9%）——"低频全局校正需要独立通路"成立；
3. 但 LFM 只是 2 个 FiLM 调制器；007a 把 LFM 从 2 块堆到 4 块为**负结果**（−0.11dB）——简单堆叠调制器不是加深通路的正确形式，低频路需要**真正的处理容量**；
4. 011k 主干对照：DEA-Net+LFM 比加宽小波高 1.1~1.4dB，**84.6~87.7% 的优势落在低频校正**——低频通路是当前最大的收益杠杆；
5. 局部/高频特征提取已充分：DEConv 是高通专家（DEA 原论文），008a 证明重采样无损化对高频修复率无影响——**不再投资局部卷积**；
6. 领域侧共识（SOTA_2025_2026 §4.2）：SFMN/EENet/AdaIR/SFAN 等 2025 顶刊顶会工作全部收敛到"空×频双域、低频全局调制与高频局部细节分工"——方向有社区印证；其中 **AdaIR（ICLR 2025）证明频率解耦的掩码可以从输入自适应生成**——这正是 LFM 缺的一半（LFM 自适应的是调制量，频率边界是固定的）。

失败对照（设计约束的来源）：

- 003d（静态全频滤波）：滤波器必须**内容自适应**、**不归一化**、**零初始化**；
- 004b（瓶颈无约束 MDTA，−4.5dB）：低频路上**不放无约束全局混合**，保持"雾幕场估计"的物理角色；
- 006a（密度信息注入，0.00dB）：不做"信息旁注"，新通路必须**直接参与特征流变换**；
- 011i/011j（输出头级小分支，60k 仅 +0.08~0.3dB）：分支补丁兑现有限，新通路要**深介入编码器特征流**。

## 2. 与最近先验工作的差异化

| 工作 | 做法 | 012 的差异 |
|---|---|---|
| AdaIR（ICLR 2025） | 输入自适应频率解耦掩码 + 双向交互，通用 all-in-one 复原 | 掩码边界的可学范围用**雾的物理先验**约束（0.02~0.15 Nyquist，来自残差频谱测量），且低频路按**空间平滑雾幕场**建模（大气散射先验），不是通用复原 |
| OctaveConv / 双流去雾（I&VC 2023） | 固定比例分频、双分辨率处理 | 边界内容自适应；且本项目有 003d 的硬分流失败教训：主链**全频保留**，分支只做增强 |
| SFMN（TIP 2025）/ SFAN（TGRS 2025） | 跨尺度特征调制 / MoE 调制专家 | 调制器形式；012 给低频路**残差块容量**（007a 证明调制器堆叠无效） |
| 009a（本仓库未实施原案） | 固定软掩码 + 池化低频分支 + 门控融合 | 012 = 009a 骨架 + 自适应边界 + 明确容量设计；**009a 本身必须先跑，作为固定边界的对照臂** |

## 3. 模块设计（`basicsr/archs/deanet_v8_arch.py`，新建）

骨架：004a（DEANetV3-LFM）。唯一变量：编码器 level2/level3 之间插入**双路频率分流块（AdaptiveDualFreqBlock）**，替换（而非叠加于）原 [2,5] 位 LFM。

```
x（编码器中层特征，B,C,H,W）
  ├─ 主链：x（全频保留，不做硬分流——003d 教训）
  └─ 双路增强：
       ┌─ 边界预测器：avgpool(x)→16×16 → 2×conv → 每图边界频率 b∈[0.02,0.15] Nyquist（sigmoid 参数化，
       │              先验中心 0.08，即 LFM 的实测有效 cutoff；可学范围由残差频谱证据约束）
       │              → 生成软掩码 M(x; b)（sigmoid 软边 0.04，与 LFM 同一掩码约定）
       ├─ 低频路：x_L = irfft(rfft(x)⊙M) → 池化到 1/8 → N×ResBlock（N=2，GELU）
       │         → 上采样回 1/4 → zero_conv → 门控 g（sigmoid，初始≈0）
       └─ 高频路：x_H = x − x_L（残差定义，天然互补）→ 1×1 投影 → 与主链 DEConv 特征并联（轻量，
                  不另建深路——高频已有 DEConv 专家，只补"被分流带走的部分"）
  out = 主链(x) + g ⊙ up(low_path(x_L)) + 1×1(x_H)     # 全部零初始化 → 初始严格恒等
```

设计约束逐条对应：

- **内容自适应边界**：b 由输入预测，但参数化范围被物理先验夹住——海雾雾幕的空间频率有大气散射模型依据，不让它学成任意滤波器（003d 机制 (a) 排除）；
- **不归一化**：保留全局 DC/色调统计（机制 (b) 排除）；
- **零初始化 + 门控**：初始严格恒等，不扰动 004a 已验证的堆叠（009a 同款工程手段，单元测试验证 max|out−in|=0）；
- **低频路有真容量**：2 个 ResBlock @1/8 分辨率，计算量可忽略；针对的是 007a 暴露的"通路太薄"，而非再堆调制器；
- **激活函数**：新增模块统一 GELU；**主干 ReLU 不动**（保持单变量可归因；激活替换预期效应 <0.1dB，在复现噪声带内，不值得单独消融——见 §6）。

参数量/显存预估：新增约 0.1~0.2M（004a 7.88M 基数 +2% 内）；低频路在 1/8 分辨率，bs20@512px 峰值预计 <46 GiB（004a 44.6），与 004a batch 严格对齐。

## 5. 8k 探针的置信度与使用规则（011 系列证据总结）

8k 探针的实证记录：

- **能有效杀死坏想法**：8k 为负的候选（011g 门控、011m 组合）没有在 60k 复活；
- **大结构效应可迁移**：011f 加宽 8k +0.43/+0.80 → 60k 官方 +0.60/+0.87（甚至扩大）；011k 主干差 8k +1.1~1.4 → 成为 011p 的决策依据；
- **小正收益不可靠**：011j 中频 8k +0.15/+0.34 → 60k 官方 +0.08/0.00（基本归零）；011i 8k Mist +0.32 未进长训；
- **早段排名会反转**：011c 2k 领先→8k 归零；011f 2k 落后（−0.25)→4k 反超→8k +0.43；011j 4k 跨卡为负→8k 同卡为正。2k/4k 只用于健康检查，不用于决策；
- **配对区间只覆盖图像抽样噪声**：复现参照（4 组同配置 8k：Dense 跨度 0.142dB、Mist 0.395dB）才是种子+环境噪声的量级——**单种子 |Δ|<0.2dB 的 8k 差异不可判读**。

决策规则（本轮固定）：

1. 固定 8k EMA 终点，逐图配对 95% 区间，不取曲线最高点；
2. Δ ≥ +0.3dB 且区间不含 0 → 直接进 60k；
3. +0.1~0.3dB → **换种子补一组 8k**，两签一致再进 60k（011j 的教训）；
4. |Δ| < 0.1dB 或轨迹恶化 → 终止，归档结论；
5. 同时看轨迹形态：2k 落后但 4k/8k 单调改善的（011f 型）不提前杀死。

## 6. 创新点定位（与"trick"的边界）

明确不宣称创新的工程项（作为最强基线的一部分，写入训练配置但不进贡献列表）：warmup、lr 2e-4、数据清洗协议、GELU 替换、损失权重的再定标。它们的处理方式：

- **数据清洗（v2 去重）是方法论贡献而非 trick**——发现并按文档化协议移除 train/test 泄漏（31 精确 + 363 近重复），这属于基准建设，和 OWH 数据集一起写；
- **超参与激活函数调整是工程项**：只在"最强基线"的意义上有价值——创新声明必须建立在最强基线之上，否则审稿人会用调参复现掉你的增益；
- **loss 改动默认是 trick**，除非它承载新的、可独立验证的机制（如 011q/011s 的频段监督对照，其科学价值在"梯度频段归因"这个分析结论，而不在那 0.x dB）；
- 012 的创新声明只有一个：**物理先验约束的自适应频率边界 + 有容量的低频平行通路**，用本项目的频段归因工具链做因果消融（边界预测器学到的 b 的分布、置零低频路的分频段退化、相对 AdaIR 式自由边界的对照）来支撑"为什么有效"。

## 7. 启动清单

1. 新建 `basicsr/archs/deanet_v8_arch.py`（DEANetV8；以 `deanet_v7_arch.py` 为骨架，加入边界预测器；注册名不可与现有重名）；009a 的 DEANetV7 已存在，012a 直接写配置即可；
2. 单元测试：任意/奇偶尺寸 fwd+bwd；初始恒等（max|out−in|=0）；新增层有梯度；边界预测器输出 b 的初值落在 [0.02,0.15] 内且初始≈0.08；
3. 冒烟训练 6 iter 全链路（dataset→model→loss→save→validation）；
4. 显存/速度探测：bs20@512px 前向+反向峰值，与 004a 对照（±10% 内可接受）；
5. 004a v2 基线确认（011p 若同配置直接复用其数字，否则补跑）；
6. 012a/012b 双卡 8k 探针，按 §5 规则评估；
7. 通过后准备 60k 配置，**先按仓库约定占号、提交并 push 编号，再开跑**；
8. 60k 终评：官方 2,711 对、`paired_eval.py` 逐图配对、频段归因（边界 b 的分布统计 + 置零消融）。

## 8. 止损与后续

- 012a（固定边界通路）就为负 → 证伪"低频平行通路"形式，方向封档，回容量主线（level1/2 加块 + 加宽）；
- 012a 正、012b 平 → 边界自适应无效，保留固定边界，转投容量/分辨率形式（012c）；
- 012b 为正但未过 §5 阈值 → 不强行进 60k，把自适应边界改作分析对象（学到的 b 与雾浓度/场景类型的相关性），作为分析型贡献写入论文；
- 与 bench 的关系：012 系列与 SOTA bench（sota_benchmark §5）共用 v2 协议与评估工具链，DEA-Net/SFMN/EENet/AdaIR 的同协议数字是 012 必须击败的对照。
