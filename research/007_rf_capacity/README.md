# 007 感受野/全局容量方向：加厚 LFM 全局调制通路（007a/007b）

> 设计文档。前置阅读：`research/004_lowfreq/README.md`（LFM 模块与机理验证）、`research/006_hihaze/README.md` §8（条件信息注入零收益的结论——本方向与其形成"容量侧 vs 信息侧"的对照）。
> 方向来源：用户判断"瓶颈在感受野侧的容量"，与文献证据一致（DEA-Net 原论文 Table IV：高分辨率层级加块 +2.52dB，融合方案改造仅 0.23dB 区间）。

## 1. 问题界定：不是感受野缺失，而是全局通路太薄

DEA-Net 主干感受野推导（r=感受野 px，j=步长，逐层累加 3×3 conv）：

| 阶段 | 计算 | r | j |
|---|---|---|---|
| down1 + 4×DEBlock（level1，全分辨率） | 1+2+8×2 | 19 | 1 |
| down2(s2) + fe + 4×DEBlock（level2） | +2+9×2×2 | 57 | 2 |
| down3(s2) + fe + 8×DEABlock（level3 瓶颈） | +2×2+17×2×4 | **197** | 4 |

理论感受野 ≈197px（有效感受野约 1/3，60~70px），对 512px 训练 crop 和 1080p+ 真实图都远非全局——这是 003 系列残差频谱分析中 55~61% 残差能量集中在 DC~0.02 超低频带的结构性原因。

004a 的 LFM 通过 FFT 软掩码 + FiLM 提供了**严格全局**的通路（频域无空间范围限制），并把 DC~0.02 残差压到五模型最低（机理验证通过）。因此现阶段瓶颈精确表述为：**全局通路存在但容量太薄**——整张图的全局校正只有 2 个 LFM 块，每块仅对低频带做一次 FiLM，调制网格仅 16×16。网络缺少做更细粒度、更深层次内容自适应全局处理的容量。

与失败方向的对照：004b（MDTA，无约束全局混合）−4.5dB、006a（密度信息注入）0.00dB——**有效的是"受物理约束的全局处理能力加深"，无效/有害的是"无约束全局混合"和"冗余信息注入"**。

## 2. 007a 设计（本实验）

**单变量改动**：level3 的 LFM 从 2 块增至 4 块，插入位置从 [2,5] 改为 [2,4,6,8]（均匀分布）。其余与 004a 完全一致：数据（Mixed 过滤 20399 对、512px、bs20）、loss（L1 1.0 + FFT 1.0 + Grad 0.2）、lr 1e-4、EMA 0.999、seed 0。

- 实现：`basicsr/archs/deanet_v5_arch.py`（DEANetV5，LFM 位置/数量/mod_size/cutoff 全参数化；`lfm_positions=[2,5], mod_size=16` 时与 004a 精确等参 7.880M，已单测验证）
- 参数量：7.971M（+0.09M，+1.2%）
- 显存/速度：bs20 @512px 峰值 45.9 GiB（004a 44.6）、1.18 s/iter（004a 1.28）——加 2 块 LFM 反而略快属测量噪声，量级一致
- 协议：**30k 短程筛选**（cosine periods [30000]），与 004a 同期轨迹对比；val_freq 1000 加密轨迹点

**判据**：
1. 主指标：Dense-test 同期 PSNR 超过 004a 轨迹（@4000/6000/8000 = 18.57/20.26/21.26；@28000+ 参考 004a 全程最优 24.86@60k，30k 短程预期 24.5+ 量级）；
2. 机理：训练完成后用 `research/004_lowfreq/tools/residual_spectrum_004.py` 复验，007a 的 DC~0.02 频段能量应 ≤ 004a（236.6M）——若指标升但低频能量没降，收益归因需重新审查（沿用 004 的判据逻辑）；
3. 止损：@10000 时 Dense 同期仍低于 004a 同期 → 判加厚无效，终止（参考 003d 教训：只看同期，不比终值）。

## 3. 007b 设想（待 007a 出结果后启动）

**单变量改动**：mod_size 16→32（更细的全局调制空间粒度），LFM 位置保持 [2,5]（与 004a 同构，隔离变量）。

- 物理依据：透射率在深度边界处并不平滑（天空/建筑边缘、雾气团块边界），16×16 网格（每格 32px@512）可能欠采样这些过渡；32×32（每格 16px）是对"调制分辨率是否欠采样"的直接检验；
- 注意 004a 的单元测试显示 mod_size 对显存几乎无影响（调制在池化后进行），007b 的 bs/lr 可与 004a 完全对齐；
- 与 007a 的关系：两实验回答"全局通路该往深里加（数量）还是往细里加（分辨率）"；若两者都有效，007d 做组合（LFM×4 + mod_size 32），再上 60k 全量；
- 备选 007c（暂缓）：瓶颈空洞卷积 [1,2,4] 循环（GCANet 式空域感受野扩展，与 LFM 的频域全局通路互补），需带平滑卷积防 gridding 伪影。

## 6. 结果与结论

### 6.1 中断点指标（@26000，训练内验证 / net_g_26000 params_ema）

| 子集 | 007a @26000 | 004a 同期 | Δ |
|---|---|---|---|
| Dense | 23.9972 / 0.8941 | 23.9483 | +0.049 |
| Mist | 29.6074 / 0.9679 | — | — |
| Moderate | 26.8977 / 0.9353 | — | — |

### 6.2 方法论修正：同期对比被 lr 调度混杂

007a 用 `periods=[30000]` 的 cosine，004a 用 `[60000]`——**同 iter 处 007a 的 lr 系统性更低、更接近收敛态**，此前逐点的"+0.1~0.2 领先"含调度水分。完整轨迹对照（`metrics_007a.csv` vs `ref_004a_dense_trajectory.csv`）：

| iter | 007a | 004a(60k 调度) | Δ |
|---|---|---|---|
| 8000 | 21.3651 | 21.2605 | +0.105 |
| 14000 | 22.8251 | 22.6450 | +0.180 |
| 18000 | 23.3878 | 23.1840 | **+0.204（峰值）** |
| 22000 | 23.7699 | 23.6159 | +0.154 |
| 26000 | 23.9972 | 23.9483 | **+0.049（衰减中）** |

领先在 @18000 见顶后随两条 cosine 的进度差扩大而收窄。更公允的对照点：**007a @26000（近收敛）23.9972 vs 004a 自己 @30000（60k 调度中点）24.1724**——007a 反而低 0.18。

**结论：007a 的 30k 筛选结果不可判读（inconclusive，偏弱偏负）**。中期领先无法排除调度混杂，终点附近的可比口径下不领先。这是本实验的设计失误（筛选协议要求严格同调度，004 系列的同期比较之所以有效是因为 003c/003d/004a/004b 全部是 60k 调度）——后续所有短程筛选必须**连 scheduler 周期数也与基线一致**，或干脆同预算全量。

### 6.3 对"全局容量"假设的影响

不证伪也不证实。007a 没有回答"LFM×4 是否有效"，只回答了"现行 30k 筛选协议无法回答这个问题"。下一步二选一（等 GPU 恢复后）：
- **干净基线**：004a 结构 + `periods=[30000]` 的 30k 对照跑（~9h），与 007a 严格同调度同期对比——回答"加厚是否有效"；
- **直接 60k 全量 007a**（~21h）与 004a 终值 24.86 对比——若对方向有信心，跳过筛选。

**最终结论（修正版）：007a（LFM×4）在同预算对照下无收益且小幅落后，为负结果，但机理叙事需修正。**
1. 007a 在占尽收敛优势（已收敛 vs 004a 未收敛中点）的情况下 PSNR 仍落后 0.11、全部 5 个频段一致落后——**无调度混杂、无预算错配，负的方向可靠**；
2. 但低频段（DC~0.02）两者几乎打平（+0.5%）——低频校正主要在 30k→60k 后半程发展（004a 自身 290→236.6M），"加厚 LFM 破坏低频结构"不成立；差距实际在**中高频段**（+2~4%），更符合"多加的模块增加了优化难度/干扰了特征学习"的一般性解释；
3. 残余不确定性：007a-60k 是否反盘未被严格排除（低频校正后半程才发展，理论上存在 60k 追平的可能），但现有全部证据无正面支持，21h 复核的期望价值低；
4. **LFM×2（004a）维持为当前最优**；加厚/加深 LFM 家族（含 007b mod_size 32）不再继续。

**对后续的影响**：007b（mod_size 32）取消（先验已大幅下调，且属同一"改 LFM"家族）；007c 的含义修正为"007a 的 60k 全量"已无必要（负结果已确证，无需 21h 复核）；容量侧若继续，转向与 LFM 无关的杠杆（level1/2 处理块——DEA-Net 消融 +2.52dB 的方向，需重新预算显存；或 GCANet 式瓶颈空洞卷积）。
