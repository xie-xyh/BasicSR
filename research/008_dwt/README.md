# 008 — 无损小波重采样（DEANetV6）：高频保真方向（008a）

> 设计文档。前置阅读：`research/004_lowfreq/README.md` §7（LFM 机理验证）与 §8（DEConv 频率响应分析）。
> 方向来源：004 系列残差频谱的再解读——按"修复率 = 1 − 残差/退化"重排各频段后，**>0.50 Nyquist 是修复率最差的频段**（见下表），而现有改进（FFT loss、LFM）的收益几乎全部来自低频。

## 1. 问题界定：高频是最少被修好的频段

`research/004_lowfreq/residual_spectrum_dense_004.csv` 换算（退化能量取自 hazy 行，残差取 004a 行）：

| 频段 | 退化能量 | 004a 残差 | 修复率 | 001→004a 修复率变化 |
|---|---|---|---|---|
| DC~0.02 | 6244.6M | 236.6M | **96.2%** | 95.3% → 96.2% |
| 0.02~0.06 | 346.6M | 59.3M | 82.9% | 81.6% → 82.9% |
| 0.06~0.15 | 197.6M | 32.1M | 83.8% | 82.7% → 83.8% |
| 0.15~0.50 | 172.1M | 31.2M | 81.9% | 80.7% → 81.9% |
| >0.50 | 74.0M | 27.2M | **63.2%** | 61.8% → 63.2% |

两点解读：
- 绝对能量上低频仍是大头（PSNR 口径的主战场不变）；但 >0.50 频段（最细纹理/边缘）的修复率全场最差，且从 001 到 004a 几乎没动过——**没有任何一次改进专门服务过高频**；
- 嫌疑机制：DEA-Net 的两处分辨率转换（`down2`/`down3` stride-2 卷积、`up1`/`up2` 转置卷积）是有损重采样，高频细节在进入瓶颈前就可能被混叠丢失，解码侧也无法还原。

## 2. 相关工作定位

小波入网络不是新点子（MWCNN 2018 的 DWT 下采样、WSAMF-Net 2023 去雾 GAN 等），但本实验的差异化与前几轮一致：**不宣称结构创新，用残差频谱诊断回答一个可证伪的问题——"有损重采样是不是高频修复率瓶颈"**。若 008a 指标升但 >0.50 频段修复率不动，则证伪该机制，归因到别处。

## 3. 008a 设计（本实验）

**单变量改动**：`down2`/`down3` 与 `up1`/`up2` 四处重采样算子换成正交 Haar 小波对：

```
WaveletDown: DWT（固定正交 2×2 核，C→4C 通道、÷2 空间，无损）→ 1×1 conv（4C→out）→ ReLU
WaveletUp:   1×1 conv（in→4·out）→ IWT（无损逆变换）→ ReLU
```

- 实现：`basicsr/archs/deanet_v6_arch.py`（DEANetV6 继承 DEANetV5，仅替换四个模块；`down1`/`up3` 是分辨率不变的投影层，不动）；
- 正交 Haar ⇒ `IWT(DWT(x)) == x`（单元测试重建误差 ~5e-7，float 精度极限）——编解码往返对细节无损；
- **参数对齐**：1×1 投影替代原 3×3 卷积，V6 总量 7.778M vs 004a 7.880M（−1.3%），比 3×3 投影方案（+7%）更贴合单变量协议；空间混合交给后续 DEBlock 的 3×3 卷积（MWCNN 式）；
- **baseline 落 004a 而非 007a**（用户提议 007a，此处修正）：007a 未判活（30k/60k 调度混杂），且 LFM×4 没有 60k 参照数据；落在 004a 上对照组（24.86@60k 全轨迹 `research/007_rf_capacity/ref_004a_dense_trajectory.csv`）现成，本实验只需跑一次。LFM×4 的判定留给 007c。

**协议**：直接 60k 全量，`periods=[60000]`、`val_freq 2000`，与 004a 严格同调度同期比较（007a 的 30k 筛选教训：异调度比较无效，本方向不再用 30k）。数据（Mixed 过滤 20399 对、512px、bs20）、loss（L1 1.0 + FFT 1.0 + Grad 0.2）、lr 1e-4、EMA 0.999、seed 0 全部与 004a 一致。

**判据**：
1. 主指标：Dense-test 同期轨迹 > 004a（参照点 @2000~@60000 见 `research/007_rf_capacity/ref_004a_dense_trajectory.csv`；终值对照 24.86/0.9006）；
2. 机理：训练完成后用 `research/004_lowfreq/tools/residual_spectrum_004.py` 复验，**>0.50 频段修复率应 > 63.2%**——这是本实验的核心假设检验，指标升但高频修复率不动则机制归因需重审；
3. 风险观察：DWT 是无损的，但 1×1 投影的空间视野（2×2）小于原 stride 卷积（3×3），层级等效感受野略缩——若整体指标下降而高频修复率升，说明视野代价盖过了保真收益。

## 4. 验证记录

- 2026-11-17 单元测试（GPU1）：DWT/IWT 在 512²/536×800/127×255（奇数）三规格重建误差 ≤4.8e-7；V6 参数量 7.778M（vs 004a −1.3%）；LFM 零初始化恒等（max|out−in| = 0）保持；两规格 fwd+bwd 通过。
- 2026-11-17 显存/速度探测（GPU1）：bs20 @512px fwd+bwd+Adam 峰值 45.4 GiB、1.26 s/iter（004a：44.6 GiB、1.28 s/iter），可同 batch 对齐。
- 2026-11-17 冒烟训练（`smoke_008a.yml`，合成数据 6 iter）：dataset→model→L1+FFT+Grad→save→validation 全链路通过，冒烟产物已清理。
