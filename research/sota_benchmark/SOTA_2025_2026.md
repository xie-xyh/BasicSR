## 4. 趋势研判（对 OWH 架构创新的五点启示）

1. **领域主线已从"合成 SOTS 刷点"全面转向"真实雾泛化"**。2025–2026 顶会去雾论文中，数据合成（HazeGen / GenHaze / HazeFlow / PEIE / Rehazing）与合成→真实域适配（PHATNet / CoA / MSDA / BiLaLoRA / KA-Net）占了一半以上。这与本项目 005 的发现（真/合雾通道离散度差 3.8 倍、真实大气光偏蓝）方向一致——**OWH 合成管线的真实性本身是可比肩顶会的研究点**。
2. **空域×频域双域建模成为高效架构共识**（SFMN / EENet / BMFH-Net / AdaIR / SFAN），且全部强调"低频全局调制与高频局部细节分工"——与本项目 003~011 的频段归因结论（LFM 是唯一验证有效的低频模块、高频假设被证伪）互相印证，说明这个方向有社区级共识，可以作为创新立足点而非风险点。
3. **扩散去雾集体转向"单步/少步 + 物理参数化"**（Hihaze / HNDiff / HazeFlow / DehazeSB / HazeMatching）。本项目 002 的负结果（裸 SD+LoRA 不可行）与领域趋势并不矛盾——成功的工作都引入了雾噪声联合建模或物理引导，而非直接微调通用扩散模型。若再做生成式，必须带物理参数化。
4. **全局上下文/大感受野仍是性能核心变量**：DehazeXL（大图 token 融合）、Mamba 系（MaIR / LMHaze / SFAN 的 MoE-Mamba）、SFMN（跨尺度调制）都在回答同一个问题——与本项目 007（感受野容量）、011k（DEA 优势 85% 在低频校正）的结论完全一致。**"海雾的空间非均匀平滑雾幕建模"是被多方验证的未解决问题**。
5. **非均匀雾与夜间雾成为新热点**（NTIRE 2026 NT-HAZE、NightHaze、MA-UND、HazeFlow 的非均匀生成、HistoFusionNet）——OWH 海上雾的空间非均匀性（006a 已观察到）可以直接对标这条线，且海上场景的高质量方法几乎空白（仅 PR 2025 的 overwater CycleGAN 与 Frontiers 的 PAC-Net 等低层级工作），竞争密度低。

## 5. OWH 同协议 bench 候选分层建议

**第一梯队（回归主干，必跑，覆盖不同归纳偏置）：**
DEA-Net（已有 004a/011p）、DehazeFormer（TIP 2023，社区标准对照）、SFMN（TIP 2025，频域调制代表）、EENet（PR 2025，高效代表）、MaIR（Mamba 代表）、AdaIR（all-in-one 频域解耦代表）、LMHaze（已移植，真实雾 MoE 代表）。

**第二梯队（真实雾/域适配，按 OWH 是否含真实测试决定）：**
CoA、KA-Net、BiLaLoRA、PHATNet、DNMGDT。

**第三梯队（生成/扩散，选 1~2 个作为生成式参照）：**
Hihaze（单步扩散，与 002/006 一脉相承，对照价值最高）、HNDiff 或 HazeFlow。

**可选物理/传统基线：** DCP、CAP（拉低基准下限，论文表格完整性用）。

**协议要点（沿用 011 系列基础设施）：** 统一 v2 清单、seed、batch、预算；先 8k 探针后 60k 终评；`paired_eval.py` 逐图配对区间；结论性数字跑 2 个种子（复现噪声带 0.06~0.2 dB）。
