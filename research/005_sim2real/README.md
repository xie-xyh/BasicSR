# 005 — sim2real 域差距测量与 LoRA 真实雾适配（前置分析）

> 研究方向：004a（DEANetV3-LFM，合成 OWH 训练）向真实雾图的域适配。
> 目标文献坐标：[BiLaLoRA（CVPR 2026）](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_Bilevel_Layer-Positioning_LoRA_for_Real_Image_Dehazing_CVPR_2026_paper.html)（LoRA+真实去雾+CLIP 无监督 loss），本方向做频率/通道驱动的差异化（见 §3）。
> 本文件当前内容：前置测量实验——真实雾与合成雾的通道统计差异（波长依赖性视角）。

## 1. 测量设计（`tools/channel_stats.py`）

动机：上一轮讨论提出"波长依赖性衰减导致通道差异"的物理先验；合成 OWH 上实测该效应微弱（B−R 透射率差仅 ~2.5pp，004a 残差通道偏差 ~0.45/255），但**真实大气散射的光谱依赖性理论上更强**。若真/合差距显著，则"光谱/通道自适应校正"可成为 LoRA 适配的物理 motivation。

测量对象与指标（全部零训练成本）：

- 数据：real-test（500 张真实雾图，无 GT）、Dense/Mist/Moderate 的 hazy（905/892/914）、Dense clear（905，GT 参照）；
- 每图统计：RGB 逐通道均值、**通道离散度**（max−min 通道差，density prior 观测量）、主导通道、**大气光颜色估计**（亮度 top-0.1% 像素的均值颜色）、整体亮度；
- 产物：`channel_stats.csv`（逐图）、`channel_dispersion.png`、`airlight_chromaticity.png`、`channel_cast.png`。

## 2. 结果（2026-11-13）

| 数据集 | 通道离散度 | B−R 偏移 | G−R 偏移 | 大气光色度 (r, b) | B 主导占比 |
|---|---|---|---|---|---|
| real-test | **0.0675** | **+0.0528** | +0.0310 | (0.3266, **0.3401**) | **74%** |
| dense-hazy | 0.0179 | +0.0073 | +0.0049 | (0.3332, 0.3330) | 56% |
| mist-hazy | 0.0533 | +0.0239 | +0.0149 | (0.3341, 0.3314) | 62% |
| moderate-hazy | 0.0299 | +0.0129 | +0.0081 | (0.3333, 0.3326) | 60% |
| GT (dense clear) | 0.1137 | +0.0564 | +0.0336 | (0.3355, 0.3292) | 65% |

三个核心发现：

1. **真实雾保留的通道差异是合成浓雾的 3.8 倍**（离散度 0.0675 vs 0.0179），甚至高于 mist 合成雾（0.0533）——合成浓雾把 RGB 三通道几乎等比例抹平（趋近同一灰色），而真实雾下通道间仍保留大量光谱信息；
2. **真实雾的大气光偏蓝**：色度 (0.3266, 0.3401) vs 中性点 (1/3, 1/3)，且分布弥散（`airlight_chromaticity.png` 中真实雾散点云明显比合成雾宽）；合成雾的大气光几乎完美中性（±0.0002 内）——**合成管线用的是白/灰大气光假设，与真实不符**；
3. **真实雾图保留了场景的蓝色基调**：B−R 偏移 +0.0528 接近 GT 的 +0.0564，而合成浓雾把它压到 +0.0073——合成雾模型把场景颜色过度中性化了。

## 3. 对 LoRA 适配设计的含义

域差距在通道/光谱维度上是**系统性且大幅的**（不是噪声级），这直接支持以下设计：

1. **通道选择性适配器有物理必要性**：真实雾的 A 有颜色（偏蓝）且逐图不同，而合成训练的 004a 只见过中性 A——LoRA 应重点挂在**承担色调/大气光校正的路径**（LFM 的 γ/β 调制器是天然挂载点，其 β 图即逐通道色调校正量）；
2. **无监督目标可以加通道先验项**：真实雾的通道离散度分布（均值 0.068）可作为自监督统计约束——输出图的通道离散度应向 GT 分布（0.114）而非合成 hazy 分布恢复；
3. **与 BiLaLoRA 的差异化落点确认**：它用 CLIP 语义方向做无监督引导（粒度粗），我们用**可测量的物理统计量**（大气光色度、通道离散度）做引导——可解释、可验证、与 CLIP loss 互补。

## 5. Step 0：real-test 无参考指标基线（2026-11-13）

配置 `test_004a_realtest.yml`（SingleImageDataset + DehazeModel，net_g_60000 params_ema），结果目录 `results/004a_realtest_eval/`（500 张输出图齐全）。指标面板：FADE/NIQE/BRISQUE 越低越好，MUSIQ/MANIQA/CLIP-IQA 越高越好。

| 对象 | FADE↓ | NIQE↓ | BRISQUE↓ | MUSIQ↑ | MANIQA↑ | CLIP-IQA↑ |
|---|---|---|---|---|---|---|
| 原始雾图（输入） | 4.3725 | 5.9878 | 47.58 | 53.23 | 0.3899 | 0.4862 |
| 004a 输出 | **2.4160** | **4.9396** | **33.53** | 52.27 | 0.3515 | 0.3466 |

**关键读数**：

1. **去雾专用与统计类指标大幅改善**：FADE −1.96（雾密度下降 45%）、NIQE −1.05、BRISQUE −14.1——去雾本身是有效的；
2. **深度感知指标反而全面变差**（MUSIQ −0.96、MANIQA −0.04、CLIP-IQA −0.14）：原始雾图在这些通用 IQA 模型眼里"更自然"（雾=低对比度+平滑），去雾后纹理/噪声/轻微色偏被惩罚。**这是已知陷阱的实测确认**：MUSIQ/MANIQA/CLIP-IQA 不能直接当作 LoRA 的训练目标（会把模型推向"不去雾"），报告时也必须与 FADE 搭配解读；
3. **目视抽查**（`failure_cases/`）：001 浓雾图远景恢复良好但天空有残雾；300 号去雾有效但水面残留蓝紫色偏——**残雾 + 色偏残留是主要失败形态**，与 §2 通道统计的预测（真实大气光偏蓝、合成模型未见过）一致。

**对 LoRA 设计的直接约束**：训练目标应以"物理先验（暗通道/CR 对比/通道离散度统计）+ FADE 改善"为导向，深度 NR-IQA 仅作报告指标；适配后 FADE 应进一步降低且 CLIP-IQA 类指标降幅收窄为目标形态。

## 6. 域内训练池审计：OverwaterHaze-ACCV2020（2026-11-13）

数据集位置：`/home/yxy/xyy/datasets/OverwaterHaze-ACCV2020`（OWH 原始 ACCV2020 发布版，148M，4843 文件）。结构：`train/clean`（2441）+ `train/hazy`（2090）+ `test/OTS90`（配对合成测试）+ `test/natural_test`（188 真实雾图）。

**性质判定**（目检 + 同名对像素差 + 暗通道统计）：

- `train/hazy` 是**真实雾照片与轻雾/近清晰图的混合**（目检样本含浓雾船只与几乎清晰的水面；暗通道均值中位 0.564，分布较宽）；同名 clean/hazy 不一定是同场景（如 23.jpg 两侧是完全不同场景），配对关系不可信——**按"无标注真实雾图源"使用，不当配对数据用**；
- 场景与 real-test 高度同源（水上/海面/船只），域匹配度优于 RTTS。

**泄漏检查**（aHash 16×16 初筛 + ORB 特征复核，方法记录：`probe/` 目录对比图）：

- aHash 初筛在该域上严重失真（雾图结构同质化，1139 假阳性）；
- ORB 复核（好匹配数）：≥30 的确证重复 2 对（train/hazy 23.jpg=real-test 146.jpeg；806.jpg=347.jpeg，同船同场景不同裁剪/分辨率）；20~30 区间 17 对混杂（抽样 24 分对为不同场景）；
- **结论：泄漏量小但非零。使用规则：剔除所有 ORB≥20 的 17 张候选后，train/hazy + natural_test 方可作为训练池**（保守阈值，牺牲少量可用图换取评测洁净）。

**可用性结论**：✅ 可作为域内主训练池。过滤后预计 1.6k~1.9k 张（剔除 19 张泄漏候选 + 按暗通道/FADE 剔除过清图），落在 LoRA 数据量甜区（1k–5k）；RTTS 仍留作通用对照池（A 域内 vs B 通用 vs A+B 消融）。

## 7. FreqDA 适配器设计：理论论证与实验方案（2026-11-13）

### 7.1 问题形式化

骨架 F₀（004a，DEANetV3-LFM，冻结）在合成域训练。真实雾图 x 的适配即学习修正项 R：y = F₀(x) + R(x)。

**核心困难是没有 GT**：真实数据上的监督只有统计先验（暗通道、对比、离散度），回答的是"雾图应该有什么统计性质"，而非"像素应等于多少"。**总原则：监督越弱，结构先验越强**——R 的结构必须替你约束"什么修正合法"，否则弱监督管不住它（R 可以靠放大噪声、制造假对比度骗过统计 loss）。

### 7.2 修正项应有的形态——物理模型推导

大气散射 I = J·t + A(1−t)。合成→真实，变的是 t 和 A：A 从中性变为偏蓝且逐图弥散（§2 实测），t 分布不同。两者**都是空间缓变量**——故所需修正大概率是低频、逐通道、平滑的量。而真实图的高频（传感器噪声、水面反光）与合成差异不大，且不该被"适配"放大。

故 R = R_L + R_H：R_L 低频修正（色调/大气光/残雾，需大感受野判断"亮区是雾还是船帆"，但低频自由度少）；R_H 高频微调（边缘残留，小感受野，且必须胆小）。

### 7.3 三个关键设计决策的论证

1. **输出端限频，而非输入端**：低频输入会丢失"判断这是雾还是白色船帆"所需的上下文（两者低通后形态相同）；输出限频只约束修正的函数形式，不损失决策证据。实现上 R_L 内部下采样 1/16 处理再上采样——低频化是结构的副产品，不是惩罚项；
2. **低秩与频带是两个正交约束**：频带限制"改哪里"，低秩限制"能改几种模式"。无低秩则 R_L 在低频带内仍可任意逐像素调制，小数据弱监督下照样过拟合；低秩 + 冻结骨架同时解决防遗忘（合成指标不崩）；
3. **R_H 零初始化 + TV 正则**：初始 y=F₀(x) 继承骨架全部能力；TV 使高频修正只能"大块连贯"，不能逐像素放大噪声——轻量是抗噪先验而非省参数。

### 7.4 假设-证据对应表

| 设计选择 | 假设 | 证据 |
|---|---|---|
| R 分低/高频两支 | 域偏移主要在低频 | §2 通道统计 + 003d/004 残差谱（55–61% 在 DC~0.02） |
| R_L 输出限频+大感受野 | 低频修正需全局上下文 | 003d（静态滤波败）/004a（LFM 有效） |
| R_H 小容量+TV | 高频适配风险是噪声放大 | 004b（无约束全局混合大败） |
| 低秩+冻结骨架 | 防遗忘+小数据可训 | 002 系列 SDLoRA 经验 |
| cutoff=0.08 起扫 | 边界应由测量定 | 残差谱分析 |

### 7.5 结构定义

```
z  = F₀(x)                          # 冻结骨架（004a params_ema）
x_L = LP(x; cutoff=0.08), x_H = x − x_L    # FFT 软掩码分解（同 LFM 口径）
R_L: avgpool16×16 → Conv1×1(3→r_L) → GELU → Conv1×1(r_L→3, 零初始化) → 双线性上采样
R_H: Conv3×3(3→r_H) → GELU → Conv3×3(r_H→3, 零初始化)   # 输入 x_H，输出 TV 正则
y  = z + R_L(x) + R_H(x_H)
```

默认 r_L=16 / r_H=4（秩分配即"域偏移主要在低频"的假设，消融里反转验证）。

### 7.6 自监督损失（真实数据，无 GT）

- **DCP 暗通道先验**：L_dcp = mean(min_c minpool(y))——雾的暗通道偏亮，向下压（权重小，防过压导致过暗）；
- **通道离散度恢复**：合成 hazy 0.018 / GT 0.114（§2）——L_disp = relu(τ − dispersion(y))，τ 取下限引导而非硬目标；
- **TV(R_H 输出)**：抗噪；
- 防遗忘依赖零初始化 + 低秩 + 短训，训后在合成 Dense-test 复查 PSNR 降幅 <0.3 dB。
